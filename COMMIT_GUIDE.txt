HOOTLY CONTRIBUTION PACKAGES
============================

Each ZIP preserves repository-relative paths. The matching <Member>-FILES.txt is an exact Git path manifest. COMMIT_GUIDE.txt and the manifest are packaging metadata and must not be committed.

EXTRACTION (PowerShell)
-----------------------
Set $repo to the recipient repository root and $member to Elegino, Malaya, Mirasol, or Simbajon. Review the target worktree first and do not overwrite unrelated local edits. These archives reflect the current workspace snapshot.

$member = 'Elegino'
$repo = 'C:\path\to\cpe314-69167-capstone-team-02'
$stage = Join-Path $env:TEMP "Hootly-$member"
$zip = Join-Path $env:USERPROFILE "Desktop\$member-Contribution.zip"
Expand-Archive -LiteralPath $zip -DestinationPath $stage -Force
$manifest = Join-Path $stage "$member-FILES.txt"
Get-Content -LiteralPath $manifest | ForEach-Object {
  $relative = $_ -replace '/', '\'
  $source = Join-Path $stage $relative
  $target = Join-Path $repo $relative
  New-Item -ItemType Directory -Force -Path (Split-Path -Parent $target) | Out-Null
  Copy-Item -LiteralPath $source -Destination $target -Force
}

Run extraction separately for each member (change $member). Then review and stage only the matching manifest. Do not use `git add .`.

SAFETY EXCLUSIONS
-----------------
No .env files or local credentials are included. online/backend/src/test/resources/application-test.yml is omitted because it contains test-only password/OTP secret values. online/frontend/e2e/mailbox.ts contains an embedded bearer token, so it and E2E specs importing it are omitted. Generated logs/build outputs/dependency folders/database files and all Markdown reports are excluded. Configure test secrets locally; do not copy credentials into a commit.
